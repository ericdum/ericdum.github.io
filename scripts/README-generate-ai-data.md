# AI可读数据生成脚本

## 简介

这个脚本用于将全站数据导出为AI爬虫友好的静态文件格式。生成的文件包含网站的所有公开信息，方便AI访问和搜索引擎索引。

## 使用方法

运行以下命令生成数据文件：

```bash
npm run generate-ai-data
```

## 生成的文件

脚本会在 `public/` 目录下生成三个文件：

1. **site-data.json** (约350KB)
   - 结构化JSON格式
   - 包含所有数据的完整结构
   - 适合程序化访问和API调用

2. **site-data.md** (约120KB)
   - Markdown格式
   - 人类和AI都易读
   - 包含完整的文本内容，适合阅读和索引

3. **site-data.txt** (约118KB)
   - 纯文本格式
   - 去除所有格式标记
   - 适合纯文本分析和处理

## 包含的数据

生成的文件包含以下内容：

- **个人信息**: 姓名、职位、简介、教育背景、技能、证书等
- **项目**: 所有项目详情，包括技术细节、影响等
- **专利**: 所有专利信息，包括摘要、状态、链接等
- **新闻**: 所有新闻文章，包括完整内容
- **教学**: 课程、学生、学生项目、学生评价等
- **生活**: 个人兴趣、活动、作品等

## 访问方式

生成的文件可以通过以下URL访问（部署后）：

- `https://your-domain.com/site-data.json`
- `https://your-domain.com/site-data.md`
- `https://your-domain.com/site-data.txt`

## 更新数据

当网站数据更新后，重新运行脚本即可更新这些文件：

```bash
npm run generate-ai-data
```

建议在以下情况下运行脚本：

- 添加新项目、新闻、专利等
- 更新个人信息
- 添加新的教学课程或学生项目
- 部署前更新数据

## 技术说明

- 脚本使用 TypeScript 编写
- 使用 `tsx` 运行 TypeScript 文件
- 自动从各个API模块获取数据
- 支持中英文双语内容
- 自动清理HTML标签，保留纯文本内容

## 注意事项

- 生成的文件会覆盖之前的文件
- 确保在运行脚本前已安装所有依赖 (`npm install`)
- 文件会生成在 `public/` 目录，这些文件会被包含在构建输出中
